# JEWEL POS V2 - Release Notes

**Version**: 1.0.0 (Production Release)  
**Release Date**: July 31, 2026  

---

### What's Included

- **Windows Workstation Module**:
  - Auto-generated sequential barcodes (`JMT000000001`).
  - HPRT HT800 TSPL Label Printing (38mm x 25mm).
  - SQLite database engine (`inventory.db`).
  - One-click Backup and Restore functionality.
  - Automatic embedded HTTP server on Port 8080.
  - Live inventory search and editing.

- **Android HandPOS Module**:
  - High-contrast, large-button POS interface.
  - Laser scanner, camera scanner, and manual entry barcode support.
  - Real-time HTTP inventory lookup over local WiFi.
  - ESC/POS thermal receipt printing.
  - Duplicate scan prevention and clear error dialogs.

- **Security & Network**:
  - 100% Offline operation. Zero cloud dependencies, zero external tracking.
  - Restrictive local network communication.
